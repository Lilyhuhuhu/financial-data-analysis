
# 金融数据分析

面向金融专硕的 Python 金融数据分析课程资料。本仓库按照知识点和学习路径重新组织，覆盖从 Python 基础、数据处理，到金融数据获取、统计建模、文本分析和综合研究项目的完整流程。

## 学习路径

| 层级 | 模块 | 核心能力 |
| --- | --- | --- |
| L0 | [课程导论与环境](00-课程导论与环境/) | 配置 Python/Jupyter，理解数据分析标准流程 |
| L1 | [Python 基础与 Pandas](01-Python基础与Pandas/) | 数据类型、函数、索引、清洗、合并、重塑、聚合 |
| L2 | [可视化与金融数据分析](02-可视化与金融数据分析/) | 描述统计、收益率、波动率、均线、成交量和交互式图表 |
| L3 | [回归与统计建模](03-回归与统计建模/) | 方差分析、线性回归、模型解释与结果表达 |
| L4 | [数据获取与综合项目](04-数据获取与综合项目/) | API、CSMAR、网络数据、股票/财务/宏观数据整合 |
| L5 | [金融文本分析](05-金融文本分析/) | 年报整理、分词、词频、情感、语调、可读性与领域词典 |
| L6 | [课程作业](06-课程作业/) | 将数据分析流程应用到公司投资价值研究 |

## 推荐使用方式

1. 先阅读 `00-课程导论与环境`，完成环境配置。
2. 按 L1 → L5 顺序学习，每个模块优先运行 notebook，再阅读课件和说明文档。
3. 使用 `04-数据获取与综合项目` 中的综合案例，练习股票、财务和宏观数据的对齐分析；其中 `.py` 文件可直接作为脚本阅读或运行。
4. 以 `06-课程作业` 为模板完成公司研究；研究报告中的公司、代码和结论应由学习者自行替换和复核。

## 环境

建议 Python 3.10+、JupyterLab 或 Notebook。常用依赖见 [`requirements.txt`](requirements.txt)。部分数据接口需要自行申请账号或配置环境变量，严禁把 API 密钥写入 notebook、文本文件或提交记录。
