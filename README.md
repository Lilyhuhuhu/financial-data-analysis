
# 金融数据分析

面向金融专硕的 Python 金融数据分析课程。课程以金融研究和公司分析中的真实问题为线索，讲授从数据获取、清洗、探索、建模到研究表达的完整方法，使学生能够把分散的行情、财务、宏观和文本资料转化为可解释的分析结论。

课程不以单纯记忆 Python 语法为目标，而是强调“提出问题—寻找数据—处理数据—选择方法—解释结果—形成报告”的完整工作流。学生在掌握工具的同时，学习关注变量定义、数据口径、时间频率、缺失值、异常值、复权方式和结论边界。

## 课程定位

本课程适合金融、经济、管理等专业中需要使用数据开展公司研究、行业分析和实证研究的学习者。课程内容兼顾三个层面：

- **工具层面**：掌握 Python、Jupyter、Pandas、可视化和常用统计分析库。
- **金融层面**：理解价格、收益率、波动率、财务指标、宏观变量和年报文本的分析含义。
- **研究层面**：能够将数据分析结果组织成图表、模型解释和公司投资价值分析报告。

## 学生实践与成果

课程作业要求学生选择一家上市公司，综合使用课程中的数据分析方法完成投资价值分析。`06-课程作业/学生作业验收` 保存了学生提交的报告和代码，供课程验收、对照和反馈使用。

从现有作业可以看到，学生已经将课堂知识用于以下实际任务：

### 1. 获取并整理金融数据

学生使用金融数据接口获取上市公司的日度行情，整理开盘价、收盘价、最高价、最低价、成交量和成交额等字段；同时获取资产负债表、利润表、现金流量表以及 GDP、CPI 等宏观指标，并完成多张数据表的字段统一、时间处理和合并。

### 2. 分析股票市场表现

学生根据收盘价计算简单收益率和对数收益率，进一步计算滚动波动率，并通过价格曲线、收益率曲线、波动率曲线、均线和成交量图观察公司的市场表现。在报告中，学生尝试将高波动区间与市场环境、行业变化、公司公告和业绩变化联系起来，而不是只停留在图表展示层面。

### 3. 进行财务绩效与风险分析

学生围绕资产规模、货币资金、总负债、资产负债率、营业收入、净利润、费用、经营现金流等指标开展纵向比较，分析公司的成长性、盈利能力、偿债能力和现金流质量。部分报告能够进一步将财务指标与股价变化进行对照，讨论“收入增长但利润下降”“利润增长但现金流承压”等常见金融分析问题。

### 4. 将宏观、市场与公司层面结合

学生不再孤立地分析一张股票价格表，而是尝试把宏观经济指标、市场波动和公司财务表现放在同一分析框架中，讨论宏观环境对行业和企业经营的可能影响，形成“宏观环境—市场表现—公司经营”的分析链条。

### 5. 使用年报文本提供补充证据

学生将公司年报 PDF 批量转换为文本，完成文本清洗、词频统计和词云展示，并进一步提取管理层讨论与分析（MD&A）内容，使用情感词典计算正负面表述、情感倾向和语调变化。文本分析为财务数据提供了补充视角，帮助学生观察公司在不同年份对技术、业务、风险、现金流和战略方向的关注重点。

### 6. 形成完整的投资价值分析报告

最终成果不是单个代码片段或一张图，而是一份包含公司介绍、行业分析、数据来源、指标计算、图表展示、财务解读、文本分析、风险提示和综合结论的研究报告。学生需要说明数据从哪里来、指标如何计算、图表反映什么、结论有哪些依据以及分析存在什么局限。

## 教学效果

从学生作业的完成情况看，课程形成了较为清晰的“知识学习—案例练习—综合应用—报告验收”闭环，主要效果体现在以下方面：

- **从会写代码到解决金融问题**：学生能够将 Pandas、可视化和统计分析方法用于真实公司，而不是只完成脱离场景的语法练习。
- **从单一数据到多源数据融合**：学生开始同时使用行情、财务、宏观和年报文本资料，理解不同数据源在频率、口径和解释范围上的差异。
- **从描述现象到解释原因**：报告中不仅展示价格和指标变化，也尝试结合行业周期、公司经营、政策环境、现金流和管理层表述解释变化原因。
- **从结构化数据到非结构化文本**：学生能够把年报文本转化为词频、情感、语调和数字化等指标，拓展了金融数据分析的范围。
- **从课堂练习到研究表达**：学生最终以投资价值分析报告的形式组织证据，训练了图表制作、结果表达、风险识别和结论边界意识。
- **形成可验收的过程性成果**：代码、数据处理过程、图表和最终报告相互对应，教师可以据此检查数据来源、计算过程和结论是否一致。

这些成果说明，学生已经初步具备用 Python 开展公司金融数据分析的能力，能够完成从原始数据到研究报告的基本闭环。与此同时，作业验收仍需重点关注数据更新、指标口径、复权处理、因果解释和投资结论的谨慎性，这些也是后续提高研究质量的方向。

## 推荐使用方式

1. 先阅读 `00-课程导论与环境`，完成 Python 和 Jupyter 环境配置。
2. 按 `01` → `02` → `03` → `04` → `05` 的顺序学习，每个模块优先运行 notebook，再阅读课件和说明文档。
3. 使用 `04-数据获取与综合项目` 中的案例，练习股票、财务和宏观数据的获取与对齐；其中 `.py` 文件可直接作为脚本阅读或运行。
4. 在 `06-课程作业/学生作业验收` 中查看学生提交的公司投资价值分析报告，对照课程要求进行验收和反馈。

## 环境

建议 Python 3.10+、JupyterLab 或 Notebook。常用依赖见 [`requirements.txt`](requirements.txt)。部分数据接口需要自行申请账号或配置环境变量，严禁把 API 密钥写入 notebook、文本文件或提交记录。
