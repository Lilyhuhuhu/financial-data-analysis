### 练习 13 标准答案

```python
# 练习 13 标准答案：写一个计算平均分的函数

def avg_score(scores):
    """接收一个成绩列表，返回平均分"""
    total = sum(scores)       # 总分
    count = len(scores)       # 科目数量
    avg = total / count       # 平均分
    return avg

scores = [80, 90, 85]
avg = avg_score(scores)
print("平均分是：", avg)
```
