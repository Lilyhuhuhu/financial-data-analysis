# **Part A · 读懂一篇文献**

------

# **模板 1｜单篇文献结构化深度剖析**

### **适用场景：**

- 精读一篇对你的论文非常重要的文献
- 写开题前、写文献综述前必须做的工作

### **输出结构：**

1. 核心论点（Thesis）
2. 论证链条（主张 → 理由 → 证据）
3. 研究设计与方法
4. 学术贡献
5. 局限性（理论/方法/数据/外推）

### **提示词：**

```
我将提供一篇对我研究非常重要的文献。请按以下结构进行分析：

1. 核心论点（2–3 句）
2. 完整论证链条（主张 → 理由 → 证据）
3. 研究设计与方法（数据、模型、识别策略）
4. 主要学术贡献（2–4 条）
5. 局限性（理论、方法、测量、外推）
```

------

# **模板 2｜单篇文献的论证结构图谱**

### **适用场景：**

- 论文逻辑复杂读不懂
- 需要快速看出“作者到底在论证什么”

### **输出结构：**

- Claim（主张）
- Reasons（理由）
- Evidence（证据）
- Counterarguments（反驳）
- Rebuttal（回应）

### **提示词：**

```
请帮我从以下文献生成一个“论证结构图谱”，内容包括：

- 主张（Claim）
- 支撑理由（Reasons）
- 关键证据（Evidence）
- 潜在反驳（Counterarguments）
- 作者回应（Rebuttal）

请用分层缩进结构呈现。
```

------

# **模板 3｜识别文献背后的隐含理论假设**

### **适用场景：**

- 批判性阅读
- 写文献综述“批判”部分
- 答辩时避免被老师问倒

### **输出结构：**

1. 所依托的理论范式（如理性选择、制度理论、行为理论）
2. 苏格拉底式质询（3–5 个问题）
3. 隐含假设（1–3 个）

### **提示词：**

```
请识别这篇文献背后的隐含理论假设，包括：

1) 该研究依托的学术范式是什么？
2) 针对研究设计、变量选择、因果解释提出 3–5 个质询。
3) 总结 1–3 个未被作者明确讨论的隐含假设。
```

------

# **模板 4｜研究方法应用萃取（事件研究法 / 面板回归 / 文本分析等）**

### **适用场景：**

- 学不懂论文的方法怎么落地
- 准备复现某项研究
- 写自己论文的方法章节

### **输出结构：**

1. 操作步骤（数据→模型→估计→稳健性）
2. 作者的最佳实践（技巧）
3. 方法的优点与局限（基于本文情境）

### **提示词：**

```
请从这篇文献中萃取该研究方法的实际操作流程，包括：

1. 数据准备（变量、来源、处理）
2. 主要方法步骤（模型设定、估计方式）
3. 稳健性检验
4. 作者实际操作中的技巧（最佳实践）
5. 优点与局限（结合本文情境）
```

------

# **模板 5｜证据有效性与支持强度评估**

### **适用场景：**

- 判断论文是否“证据充分”
- 写文献综述的“批判部分”
- 做论文审稿式阅读训练

### **输出结构：**

1. 证据类型
2. 有效性问题
3. 支持强度评估

### **提示词：**

```
请对以下论文的证据质量进行评估：

1. 将证据按类型分类（统计、访谈、案例、档案等）
2. 针对每种证据提出关键有效性问题
3. 判断整体证据对核心主张的支持强度（强/中/弱），并说明理由
```

# **Part B · 多篇文献的综合**

------

# **模板 6｜多篇文献的综合述评（文献综述核心技能）**

### **适用场景：**

- 写毕业论文“文献综述”章节
- 避免学生常见错误：逐篇罗列、缺少整合

### **输出结构：**

1. 主题聚类（2–3 个主题块）
2. 逻辑主线
3. 一段式综合述评

### **提示词：**

```
请对以下多篇文献进行“综合述评”，包括：

1. 根据研究视角/方法/发现，分成 2–3 个主题块
2. 设计合适的叙事主线（从理论到实证 / 从宏观到微观等）
3. 写一段综合性述评，将文献有机整合，而不是逐篇介绍
```

------

# **模板 7｜对立观点的辩证整合**

### **适用场景：**

- 同一主题文献得出冲突结论
- 综述中需要展示“争论”

### **输出结构：**

- 争论焦点
- A 与 B 的“对话式比较”
- 综合性观点（第三条路径）

### **提示词：**

```
以下两篇文献在同一主题上得出相反结论，请分析：

1. 冲突的根本来源是什么？（理论/方法/证据）
2. 用“学者 A …；学者 B …”的结构呈现双方逻辑
3. 尝试给出一个综合性视角或进一步研究问题
```

------

# **模板 8｜核心概念对比矩阵**

### **适用场景：**

- 多篇论文都用“创新”、“ESG”、“绩效”等同一概念时
- 需要理解“概念差异导致研究差异”

### **对比维度：**

- 核心定义
- 理论渊源
- 测量方式
- 研究使用方式（自变量/因变量等）

### **提示词：**

```
请为以下论文构建一个概念对比矩阵，维度包括：

- 作者与年份
- 概念的核心定义
- 理论渊源
- 测量/操作化方式
- 在研究中的功能（自变量/因变量）

最后给出一段总结，说明关键差异及其影响。
```

------

# **模板 9｜从文献集合中提炼学术辩题**

### **适用场景：**

- 想快速知道一个领域的核心争论
- 写文献综述的“争议点”部分

### **输出结构：**

1. 领域共识
2. 主要分歧
3. 2–4 个学术辩题（每个有正反观点）

### **提示词：**

```
请从这些文献中提炼该领域的“学术辩题”，包括：

1. 普遍共识
2. 明显分歧
3. 2–4 个核心辩题（含正反观点）
4. 指出哪些是经典争论、哪些是最新前沿
```

# **Part C · 选题与写作**

------

# **模板 10｜从文献局限挖研究缺口（最关键的选题能力）**

### **适用场景：**

- 开题报告
- 论文选题
- 研究创新点设计

### **输出结构：**

1. 多维度局限
2. 转化为新研究问题
3. 小型研究方案（数据+方法+贡献）

### **提示词：**

```
请从以下文献中识别其最重要的局限，包括：

- 理论视角
- 研究设计（样本、时间、情境）
- 变量测量
- 方法与识别策略

将其中 1–2 个局限转化为“可研究的问题”，并为每个问题写一个迷你研究方案（数据、方法、潜在贡献）。
```

------

# **模板 11｜文献与自身研究的关联矩阵**

### **适用场景：**

- 明确“这篇文献对我论文有什么用”
- 构建文献综述逻辑框架

### **维度：**

- 理论启发
- 方法借鉴
- 支撑性证据
- 可批判对象
- 对研究设计的警示

### **提示词：**

```
请将以下文献与我的研究建立关联矩阵，维度包括：

1. 理论上的启发
2. 方法上的借鉴
3. 可为我所用的证据
4. 可作为批判对象或对话对象
5. 对我研究设计的警示

并给出一句总结：“这篇文献对我最重要的价值在于……”
```

------

# **模板 12｜将文献笔记转化为写作素材模块**

### **适用场景：**

- 阅读后满篇笔记却写不出文献综述
- 想把碎片化笔记变成“可用的段落”

### **输出结构：**

1. 分类（引言、综述、方法、讨论）
2. 句子化（学术表达）
3. 模块化（段落）

### **提示词：**

```
以下是我对某篇文献的零散笔记，请帮我：

1. 将其按章节用途分类（引言/文献综述/方法/讨论）
2. 将要点“句子化”，写成规范的学术表达
3. 整理成可直接用于写论文的“素材模块”
```
