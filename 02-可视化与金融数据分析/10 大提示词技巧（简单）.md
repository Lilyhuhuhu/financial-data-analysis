# 📘 **10 大提示词技巧**

------

## ## **1. 费曼学习法（Feynman Technique）**

### **📌 技巧说明（适用于复杂金融概念）**

用“讲给外行”的方式逼自己把复杂概念讲清楚，例如风险中性定价、信用利差、贝塔估计、VAR/SVAR 模型等。

------

### ❌ **差的提示词**

```
解释一下期权的 Delta。
```

### ✅ **好的提示词（费曼法 + 金融类比）**

```
请像给一个完全不懂金融的朋友讲解一样，
用生活类比（如雨伞对天气变化的敏感度）解释期权 Delta，
不使用公式，同时告诉我它在风险对冲中的直觉意义。
```

## ## **2. 帕累托原则（80/20 原则）**

### **📌 技巧说明**

聚焦最关键的 20% 金融知识点，解决 80% 工作痛点（如估值、信用分析、财报解读）。

------

### ❌ **差的提示词**

```
总结公司估值的方法。
```

### ✅ **好的提示词（80/20 + 实务）**

```
请按 80/20 原则，仅总结能解决 80% 估值场景的两种关键方法：
DCF 与可比公司法，并说明它们为何是最重要的。
```

## ## **3. 番茄工作法（Pomodoro）**

### **📌 技巧说明**

把金融学习任务拆成“25 分钟 × 多个周期”，提升效率（读论文、写报告、建模型）。

------

### ❌ **差的提示词**

```
帮我规划如何读这篇金融论文。
```

### ✅ **好的提示词**

```
请将阅读这篇资产定价论文拆成 4 个 25 分钟番茄钟，
并为每个番茄钟给出：
1. 目标
2. 要阅读的部分
3. 我必须输出的笔记
```

## ## **4. SQ3R 阅读法（论文阅读神器）**

### **📌 技巧说明**

适用于英文金融论文：预览 → 提问 → 阅读 → 复述 → 回顾。

------

### ❌ **差的提示词**

```
帮我读懂这篇论文。
```

### ✅ **好的提示词（SQ3R + 金融论文）**

```
请按 SQ3R 方法帮我阅读这篇绿色金融论文：

S 预览：提取研究问题、模型结构  
Q 提问：生成 5 个阅读时应关注的问题  
R 阅读：解释核心方程与变量含义  
R 复述：用通俗语言重写模型直觉  
R 回顾：给 3 个检验理解的问题
```

## ## **5. 艾宾浩斯曲线（复习节奏设计）**

### **📌 技巧说明**

金融模型、统计、资产定价知识高度抽象，需要科学复习。

------

### ❌ **差的提示词**

```
给我一个金融考试复习计划。
```

### ✅ **好的提示词**

```
请基于艾宾浩斯遗忘曲线，为《固定收益分析》设计复习节奏
（5 分钟、30 分钟、12 小时、1 天、3 天、7 天），
并告诉我每个阶段应复习哪些重点（如久期、凸性、利差曲线）。
```

## ## **6. 主题交叉学习法（Cross-Learning）**

### **📌 技巧说明**

通过不同金融主题的类比，加深理解（例如债券久期 vs 股票 Beta）。

------

### ❌ **差的提示词**

```
讲一下企业杠杆率。
```

### ✅ **好的提示词（主题交叉）**

```
请交叉讲解“企业杠杆率”和“银行资本充足率”，
指出它们在风险管理上的相似性、差异，
以及为何两个行业都用“杠杆”来衡量抗风险能力。
```

## ## **7. 双编码理论（Dual Coding）**

### **📌 技巧说明**

用“图示 + 文字”结合来理解金融：收益率曲线、风险溢价、期权希腊字母等。

------

### ❌ **差的提示词**

```
解释收益率曲线。
```

### ✅ **好的提示词（双编码 + 图示）**

```
请用双编码方式解释收益率曲线：

1. 用文字说明正常、倒挂、平坦三种利率期限结构  
2. 用 ASCII 图画出三种曲线的示意图
```

## ## **8. GROW 模型（目标-现状-方案-意愿）**

### **📌 技巧说明**

适合职场提升、写作规划、技能路径设计。

------

### ❌ **差的提示词**

```
帮我提高财报分析能力。
```

### ✅ **好的提示词（GROW + 金融能力）**

```
请根据 GROW 模型帮我提升财报分析能力：

G 目标：达到能独立撰写信贷尽调报告  
R 现状：分析我目前的知识短板  
O 方案：给出提升路径（指标拆解 + 学习顺序）  
W 意愿：列出我本周必须完成的 3 项行动
```

## ## **9. 分块学习法（Chunking）**

### **📌 技巧说明**

把复杂数学模型拆成易吸收的小块，例如 VAR、GARCH、SVAR、CAPM。

------

### ❌ **差的提示词**

```
讲清楚 VAR 模型。
```

### ✅ **好的提示词（分块表达）**

```
请把 VAR 模型拆成 4 个模块，每个模块 150–200 字：

1. 模型的直觉  
2. 数学结构（写出核心形式）  
3. 估计方法（OLS、信息准则、稳定性）  
4. 金融应用（利率预测、宏观冲击分析）
```

## ## **10. 多感官学习法（Multisensory Learning）**

### **📌 技巧说明**

“读—听—说—写”同时刺激多个通道，强化记忆（适合公式类内容）。

------

### ❌ **差的提示词**

```
教我记住 CAPM。
```

### ✅ **好的提示词（多感官）**

```
请为我制定 CAPM 多感官学习方案：

读：用 150 字解释 CAPM 的核心直觉  
听：生成一段 30 秒可朗读的解释  
说：提供一个我能在 1 分钟复述的版本  
写：给 3 个手算题，让我计算预期收益率
```
