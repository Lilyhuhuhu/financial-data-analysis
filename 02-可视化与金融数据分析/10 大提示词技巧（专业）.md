# ## **1. 费曼学习法（Feynman Technique）**

### **📌 技巧说明

费曼法强调：**将复杂金融概念用朴素语言重新表述**。核心是检测你是否真正掌握了资产定价直觉，而不是藏在公式背后。

### **📌 金融专业场景**

- 解释 **信用利差为什么存在**
- 向非技术部门说明 **SVAR 的识别逻辑**
- 讲清 **气候 Beta（βCCN）** 或 **绿色溢价** 的经济含义
- 帮助团队理解 **流动性因子为何影响回报**

------

### ❌ **差的提示词**

```
解释一下信用利差。
```

### ✅ **好的提示词（专业版）**

```
请用费曼学习法解释“信用利差”，
要求：
1. 不使用任何复杂公式；
2. 使用一个生活类比（如借钱给不同朋友的风险差异）；
3. 说明它背后的三大驱动力：违约风险、流动性风险、风险偏好。
```

------

### 🎯 **课堂练习**

**请用费曼法解释“期限溢价”，要求：**

- 不能出现数学公式
- 必须包含一个生活类比
- 同时说明期限溢价为什么在经济衰退前会下降

# ## **2. 帕累托原则（80/20 原则）**

### **📌 技巧说明**

在金融研究和实务中，20% 的变量/信息往往决定 80% 的判断，如：收益分布的尾部、影响利差的核心因子、估值模型中的关键假设。

### **📌 金融专业场景**

- 资产定价模型：最核心的风险因子
- 信用评估：决定违约概率的关键指标
- DCF：影响估值的两大敏感变量（增长率、折现率）
- 投资组合：少数几个因子解释大部分波动

------

### ❌ **差的提示词**

```
总结估值模型。
```

### ✅ **好的提示词**

```
请基于 80/20 原则，提炼能解决 80% 实际估值场景的两个关键方法：
DCF 与可比公司法。
并用结构化方式说明它们各自最敏感的两个变量。
```

------

### 🎯 **课堂练习**

请学生用 80/20 原则总结：
 **“一只债券的收益率受哪些关键因素驱动？”**
 要求：仅保留 **最重要的 20% 因素**（例如：信用风险、利率水平）。

# ## **3. 番茄工作法（Pomodoro）**

### **📌 技巧说明**

金融研究任务复杂，需拆分为可管理块：读论文、跑回归、处理数据、写方法部分。

### **📌 金融专业场景**

- 阅读长篇论文（Engle 2020、Mertens & Ravn 2012）
- 写作文献综述
- 整理 Stata / Python 回归结果
- 构造因子、计算回报序列

------

### ❌ **差的提示词**

```
帮我读懂这篇资产定价论文。
```

### ✅ **好的提示词**

```
请将阅读这篇资产定价论文拆成 4 个 25 分钟番茄钟。
每个番茄钟需给出：
1. 阅读目标
2. 关注的模型部分
3. 我必须输出的笔记（如方程、因子定义、关键假设）
```

------

### 🎯 **课堂练习**

让学生把下面任务切成 4 个番茄钟：
 **“用 Python 重现某篇文章的 βCCN 气候风险因子回归。”**

# ## **4. SQ3R 阅读法（论文阅读框架）**

### **📌 技巧说明**

用于高效理解英文学术论文。特别适用于资产定价、绿色金融、宏观金融论文。

### **📌 金融专业场景**

- 解读 SVAR 识别假设
- 提炼 DSGE 模型方程
- 理解实证策略（PSM、双重差分、工具变量）
- 把文献的贡献拆成“模型—数据—识别—结论”

------

### ❌ **差的提示词**

```
帮我总结这篇论文。
```

### ✅ **好的提示词**

```
请按 SQ3R 方法阅读这篇气候金融论文：

S 预览：提取研究问题、假设、核心模型结构  
Q 问题：生成 5 个我应关注的识别问题  
R 阅读：逐段解释方程、变量、估计策略  
R 复述：将模型直觉转为简单语言  
R 回顾：给出 3 个检验我是否真正理解的问题
```

------

### 🎯 **课堂练习**

让学生用 SQ3R 阅读：
 **“房价与货币政策的 SVAR 研究”**
 并必须写出：

- 一个研究问题
- 两个识别假设
- 三个潜在缺陷

# ## **5. 艾宾浩斯曲线（金融模型复习路径）**

### **📌 技巧说明**

量化金融公式多、推导长，需要科学复习机制巩固。

### **📌 金融专业场景**

- 资本资产定价（CAPM / ICAPM）
- 债券凸性与久期
- VAR 稳定性条件与脉冲响应
- GARCH 波动率模型

------

### ❌ **差的提示词**

```
帮我安排复习计划。
```

### ✅ **好的提示词（专业版）**

```
请基于艾宾浩斯遗忘曲线，为《固定收益分析》制定复习节奏：
（5 分钟、30 分钟、12 小时、1 天、3 天、7 天）
并为每个阶段指定要复习的主题（久期、凸性、利率期限结构、利差模型）。
```

------

### 🎯 **课堂练习**

要求学生：
 **将“CAPM 推导 + 经济直觉”按艾宾浩斯曲线设计自己的复习计划**。

# ## **6. 主题交叉法（Cross-Learning）**

### **📌 技巧说明（专业版）**

通过“类比 + 对比”理解不同金融体系之间的逻辑。

### **📌 金融专业场景**

- 债券久期 vs 股票 Beta
- 银行业资本充足率 vs 企业杠杆率
- 气候风险溢价 vs 政策不确定性溢价
- 绿色债券 vs 普通债的流动性差异

------

### ❌ **差的提示词**

```
讲一下流动性风险。
```

### ✅ **好的提示词**

```
请交叉讲解“债券流动性风险”和“股票市场冲击成本”。
要求：
1. 指出两者共同的风险来源；
2. 用对比方式说明数据如何测量；
3. 用一个场景说明两类资产的流动性风险在危机中如何传导。
```

------

### 🎯 **课堂练习**

让学生交叉解释：
 **“信用利差” vs “TED 利差”**
 并说明两个指标对市场压力的不同反映机制。

# ## **7. 双编码理论（Dual Coding）**

### **📌 技巧说明**

图与文字同时呈现，可提升对复杂模型结构的理解。

### **📌 金融专业场景**

- 画出收益率曲线三种形态
- 用图示说明 CAPM 的 SML
- 用 ASCII 图表示 SVAR 冲击路径
- 用框图展示 DSGE 的状态变量与跳跃变量

------

### ❌ **差的提示词**

```
解释收益率曲线。
```

### ✅ **好的提示词**

```
请用“双编码”方式解释收益率曲线：
1. 文字说明正常、倒挂、平坦的期限结构；
2. 用 ASCII 图绘制三种曲线的形状；
3. 并解释债市如何从“正常”走向“倒挂”。
```

------

### 🎯 **课堂练习**

让学生绘制 ASCII 图：
 **使用双编码画出“金融周期”与“信用周期”的先后关系图。**

# ## **8. GROW 模型（目标-现状-方案-意愿）**

### **📌 技巧说明**

特别适合金融从业者职业规划、研究路径设计、论文推进。

### **📌 金融专业场景**

- 提升信用分析能力
- 规划论文研究流程
- 制定量化策略学习路径
- 设计 ESG 研究计划

------

### ❌ **差的提示词**

```
帮我提高财报分析能力。
```

### ✅ **好的提示词**

```
请根据 GROW 模型帮我提升财报分析能力：

G 目标：独立完成信贷尽调  
R 现状：指出我目前的技术缺口  
O 方案：给出学习路径（指标拆解 + 财务比率 + 风险识别）  
W 意愿：列出未来 7 天必须完成的 3 项行动
```

------

### 🎯 **课堂练习**

学生需用 GROW 制定：
 **“未来一个月提高量化编程能力（Python / Stata）”** 的行动计划。

# ## **9. 分块学习法（Chunking）**

### **📌 技巧说明**

把大型模型拆成可操作模块，特别适用于复杂计量模型。

### **📌 金融专业场景**

- VAR/SVAR
- GARCH
- Fama-MacBeth
- 绿色溢价分解（βCCN、气候新闻、物理风险）

------

### ❌ **差的提示词**

```
讲一下 VAR 模型。
```

### ✅ **好的提示词**

```
请将 VAR 模型拆成 4 个逻辑块，每块 150–200 字：

1. 模型直觉（互为预测的系统）  
2. 数学结构与稳定性条件  
3. 估计方法（OLS + 信息准则）  
4. 金融应用（脉冲响应、方差分解）
```

------

### 🎯 **课堂练习**

学生必须将 **GARCH(1,1)** 拆成三块：

- 直觉
- 数学结构
- 金融意义（波动聚集性、风险管理）

# ## **10. 多感官学习法（Multisensory Learning）**

### **📌 技巧说明**

结合“读—听—说—写”的方式掌握定价模型、信用模型、风险因子。

### **📌 金融专业场景**

- CAPM / Fama-French
- Hull-White 利率模型
- Black-Scholes 推导
- DSGE 状态转移方程

------

### ❌ **差的提示词**

```
教我 CAPM。
```

### ✅ **好的提示词**

```
请为 CAPM 制定一个多感官学习方案：

读：150 字解释 CAPM 的经济直觉  
听：生成一段 30 秒可朗读音频脚本  
说：提供一个我能在 1 分钟内复述的版本  
写：给出 3 个 CAPM 手算题（含答案）
```

------

### 🎯 **课堂练习**

让学生：
 **根据多感官学习法，复述 ICAPM 的经济含义，并设计 2 个题目考核同学。**
